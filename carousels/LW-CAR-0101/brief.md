## Маркетингова логіка
- **Тиждень на 5 днів:** push, pull, legs, upper, lower. Зв'язок із карткою Push Pull Legs у Harda.

## Тиждень
- mon: push
- tue: pull
- wed: legs
- thu: rest
- fri: upper
- sat: lower
- sun: rest

**day 1 — push:** bench press 3 x 6-8, incline db press 2 x 8-12, seated db press 2 x 8-12, lateral raise 3 x 12-20, rope pushdown 2 x 10-15
**day 2 — pull:** pull-ups 3 x 6-10, chest-supported row 3 x 8-12, face pull 2 x 12-20, incline db curl 2 x 8-12, hammer curl 2 x 10-12
**day 3 — legs:** back squat 3 x 6-8, romanian deadlift 3 x 8-10, leg extension 2 x 10-15, lying leg curl 2 x 10-15, standing calf raise 2 x 10-15
**day 4 — upper:** machine chest press 2 x 8-12, lat pulldown 2 x 8-12, cable lateral raise 2 x 12-20, cable curl 2 x 10-15, overhead cable extension 2 x 10-15
**day 5 — lower:** leg press 3 x 8-12, hip thrust 2 x 8-12, seated leg curl 2 x 10-15, walking lunges 2 x 10-12, seated calf raise 2 x 10-15
