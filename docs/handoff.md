# Поточний стан — 2026-10-18

## Зроблено
- Публічний lightweight-carousels створено; документи записані напряму на GitHub, без локального checkout.
- Записано базову палітру; стиль НЕ затверджено.
- Прочитано старий exercise-images workflow і підготовлено три ролі: координатор, Claude-копірайтер, візуальний агент.
- За останньою вказівкою прибрано рецензента, автоматичний візуальний QA та додаткові аудити після генерації. Готове дивиться власник.

## Ще не зроблено

- Claude, хмарна генерація, віддалений канал outputs та розклад не підключені.
- Немає затвердженого стилю або production assets.

## Наступна дія
Власник додає скриншоти в references/CAROUSELS.md. Після цього працюємо з конкретними REF-ID й опрацьовуємо стиль. При недоступності зображень у хмарному середовищі фіксуємо точний блокер, а не вигадуємо відповідність.

На комп'ютер власника нічого не завантажувати. Масовий випуск зараз не запускати.

## Оновлення: продуктові скриншоти
Створено references/APP-SCREENS.md для оригінальних екранів із групуванням APP-XXX. Зараз порожньо. Власник може паралельно наповнювати CAROUSELS.md прикладами й APP-SCREENS.md продуктовими матеріалами.

Сцена з рукою/телефоном і точне накладання UI поки лише спроєктовані. Не стверджувати, що це автоматично працює. Для наступного завдання вибрати конкретний APP-ID, перевірити доступність його оригіналу в обраному середовищі та визначити фактично доступний спосіб вставлення. Без нових агентів QA, локального клонування або завантаження на комп'ютер власника.
