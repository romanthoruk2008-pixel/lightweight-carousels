Спільна пам'ять і проєкт процесу створення фітнес-каруселей: Claude пише тексти, Codex/ChatGPT веде візуальне виробництво.

**Поточний етап: продумуємо workflow. Стиль НЕ затверджено.** Записано лише базову палітру. Best Arm Day — експеримент; конкретний фінальний CTA ще потребує роботи.

## Основа процесу

Стабільні ID → пакети завдань → тексти → візуали → окремі перевірки → фідбек → перевірене віддалене збереження.

Попередній exercise-images workflow зберігає корисну модель пакетів, manifests, історії спроб і handoff. Для каруселей одна повна серія має одного візуального виконавця; різні каруселі можна буде виконувати паралельно після пілоту.

## Стан підключень

Claude, хмарний генератор, передача binary та автоматичні запуски поки не налаштовані. У репозиторії — документація та progress, без імпортованих слайдів проби.

За вимогою власника не створювати checkout і нічого не завантажувати на його комп'ютер.
