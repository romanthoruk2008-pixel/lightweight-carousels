# Lightweight Carousels

**Поточний напрям: максимально близько відтворювати надані каруселі — тему, текст і голос, ілюстрації, композицію й порядок слайдів. Зміни: акцентні кольори та фактичний шрифт Lightweight; продуктовий фінал адаптувати до реальних функцій апки.**

Детальна актуальна вказівка: [BRAND.md](docs/BRAND.md) і [CONTENT-BRIEF.md](docs/CONTENT-BRIEF.md). Попередній експеримент Best Arm Day не є master. Шрифт — Rubik; конкретний наступний output ще не визначений. Зараз записано правила; генерацію не запущено.

---


Спільна пам'ять і проєкт процесу створення фітнес-каруселей: Claude пише тексти, Codex/ChatGPT генерує візуали.

**Стиль НЕ затверджено.** Записано лише базові кольори. Best Arm Day — експеримент.

## Куди додавати приклади

**[Відкрити спільний файл референсів](references/CAROUSELS.md)** → Edit (олівець) → перетягнути скриншоти під потрібний REF-XXX → Commit changes.

Один розділ = одна карусель. Зображення зверху вниз = порядок слайдів. Перейменовувати всі скрини не потрібно. Файл зараз містить порожні місця, без імпортованих картинок.

## Процес

Референси → координатор готує завдання → Claude пише тексти → візуальний агент генерує серію → власник переглядає.

За рішенням власника окремого рецензента й автоматичного візуального QA після генерації немає. Зберігаємо progress і outputs; перевірки не позначаємо виконаними, якщо їх не проводили.

## Стан

Claude, хмарний генератор, віддалений канал outputs і автоматичні запуски ще не підключені. На комп'ютер власника нічого не завантажувати й не клонувати.

## Екрани застосунку

**[Додати оригінальні екрани Lightweight](references/APP-SCREENS.md)** → Edit → назва й скриншот під APP-XXX → Commit changes.

Один APP-ID = один екран/стан. Ці матеріали використовуються у продуктових слайдах і макетах із телефоном. Вставлення точного UI в згенеровану сцену поки лише запропоновано, не налаштовано. Файл зараз містить порожні місця; стиль каруселей не затверджено.
