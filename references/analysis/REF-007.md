## C. Marketing analysis

**Hook.** Two-word problem-callout question ("WEAK BACK?") in giant condensed type + aspirational flexing back render. Works because it is instantly self-diagnostic (every lifter wonders if their back lags), short enough to read in <1s, and the image shows the desired outcome. Slide 2's "Let's Fix That" answers it immediately, promising a solution.

**Formula.** "Weak [body part]? → anatomy map of sub-muscles → one slide per sub-muscle (number, muscle name + function in parentheses, sets x reps, Exercise A OR Exercise B) → 'Trying to build muscle? progressive overload → app score' plug." Effectively "5 targets × 2 exercise options = complete back workout".

**Value / saveability.** High: a complete, gym-ready back day (5 movement slots, sets/reps, alternatives for equipment availability). The "OR" option format adds flexibility. 20K saves on 33.1K likes confirms it's used as a reference.

**Retention mechanics.** Numbered badges 1–5 (progress cue), slide 2 previews 4 groups (open loop: viewers swipe to see each), consistent template so each swipe is predictable/cheap to consume, minimal text per slide, muscle-highlight visual repeated for scannability. Lats split into "Adduction"/"Extension" adds a "smart/expert" curiosity element.

**CTA.** Implicit only, on the last slide: "Check your progress overload score to make sure you're still growing." No "download", app name in copy, or "link in bio". Caption has no CTA either. Follow button is TikTok's own.

**Brand integration.** Soft sell: 7/8 slides pure value, final slide pivots via a general training principle (progressive overload) to a proprietary feature (Arrow Score 0–100 ring + "Arrow Coach" AI insight card that comments on consistency vs strength and last-session muscle volume). Brand appears only in UI text and the account. The product shown: progress/overload score, AI coach summary, per-muscle session volume tracking.

**Claims to verify / questionable.**
- "Lats (Adduction)" vs "Lats (Extension)" split: biomechanically the lats do both shoulder adduction (vertical pulls) and extension (rows with elbows tucked); framing is defensible but commenters dispute that close-grip rows are lat work ("for mid back"). Verify/phrase carefully.
- "Traps" slide highlights **upper** traps but prescribes T-Bar Row / Wide-Grip Row, which mainly hit **mid/lower traps + rhomboids**; upper traps are typically trained with shrugs. Visual-exercise mismatch.
- Rep/set prescriptions (2-3 x 6-10, 2-3 x 8-12) are generic, not sourced.
- "Weighted Pull-ups" as option for a "weak back" — inappropriate for beginners (top comment, 49 likes).
- Hinge "*Performed on leg day" — fine as programming note, but means erectors may get double work; opinion not fact.
- Slide 8 copy grammar: "be consistently progress overloading" (error); "progress overload score" is a proprietary metric, not a real training measure.
- Caption typo "simpliest".

**Weaknesses / pushback.** Exercise-muscle mapping accuracy (lats extension vs mid back), beginner mismatch (weighted pull-ups), upper-trap visual vs row exercises, no biceps/teres/rhomboid mention, sloppy grammar on plug slide. Comments are few (21) — the post drives saves, not discussion.

**Notes for Lightweight adaptation.** Product-specific material to substitute: slide 8 only (Arrow Score ring, "Arrow Coach" card, "progress overload score"). Must be replaced with a real Lightweight feature — do not invent a score/AI coach if Lightweight lacks it. Slides 1–7 are product-neutral and can be kept verbatim (consider fixing factual issues only if the owner approves).
