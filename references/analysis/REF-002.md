## C. Marketing analysis

**Hook type & why it works.** Superlative "ultimate X" list promise ("THE ULTIMATE PULL DAY") + a big, attractive anatomy render with the target muscles lit in neon green. It's a broad, high-intent topic (every lifter on a PPL split has a pull day), instantly understood in 0.5 s (4 words), and the image visually "previews the payoff" (wide back, big biceps). No curiosity gap in text; the pull is "complete ready-made workout inside".

**Formula.** "The Ultimate [Split Day]" = 1 cover + N exercise slides (#N + name + sets×reps + one-sentence cue + illustration) + 1 app slide. Here: 6 exercises ordered compound → isolation (vertical pull, horizontal pull ×2, rear delt, biceps ×2), mirroring the caption, which repeats the full list as text.

**Practical value / saveability.** High and immediately usable: a complete session with sets/reps (2–3 × 6–10 for compounds, 2–3 × 8–12 for isolation) and one form cue per lift. 53K saves vs 83.3K likes confirms it's saved as a gym reference. Value is "what to do", not "why" — which is exactly where commenters ask questions.

**Retention mechanics.** Numbered #1–#6 (implied completeness; viewer swipes to see the whole workout); rigid consistent template (fast scanning, low cognitive load); identical illustration style keeps visual novelty via a new machine/pose each slide; low text density (~20–23 words) means each swipe is quick; caption repeats the list so the slide content is also findable without swiping. No explicit "swipe" prompts.

**CTA.** Implicit only. Final slide: "Track Your Workouts. Build Strength & Muscle Faster." with the app UI. No verbal "download", app name, or "link in bio" visible on slides (bottom crop caveat); caption has no CTA either; brand is carried by the account name "Arrow"/handle "arrowfitnessapp".

**Brand/app integration.** Soft sell: 7/8 slides are pure value, 1/8 is product. Product slide reuses the same illustration style (hand drawn in the same line-art) so it feels native, and shows the app logging the very workout just taught ("Pull Day", Seated Row Machine, Unilateral). Features shown: named workout + session timer, per-exercise card, unilateral toggle, set log (weight × reps), set-repeat/marker icon, front/back muscle map highlighting worked muscles, Remove Set / Drop Set / Add Set buttons, delete workout. For Lightweight, the equivalent slide must show only real Lightweight features (to be confirmed by owner; do not copy Arrow's feature set by assumption).

**Factual claims to verify / questionable.**
- Slide 2: "Use a wider grip" — the implication that wider grip is better for lats is weakly supported; grip-width differences in lat activation are small in the literature. Verify or keep as a cue, not a claim.
- Slide 3: "To grow a thicker back, focuses on squeezing (retracting) your shoulder blades" — "thickness via retraction" is common gym lore, not an established mechanism; also grammar error "focuses".
- Slide 5: "Keep your upper arm straight and stop just before you’re about to squeeze your scapula" — cue for rear-delt bias (avoid scapular retraction) is reasonable, but "upper arm straight" is unclear wording (meant: arms nearly straight/fixed elbow angle).
- Slide 7: "These grow your forearms and add serious size to your arms" — hammer curls mainly train brachioradialis and brachialis (plus biceps); "serious size" is hype.
- Slide 6: "Any bicep curl variation works fine" — broadly defensible, but generic.
- Slide 8: "Build Strength & Muscle Faster" — unsubstantiated product-outcome claim (tracking supports progressive overload, but "faster" is a promise). For Lightweight, flag as a claim needing owner approval.
- Sets/reps (2–3 × 6–10 / 8–12) are standard hypertrophy ranges; fine, but the total volume and rest are not stated.

**Weaknesses / pushback.**
- Top visible comment (434 likes): redundancy — "no point doing reverse fly if ure doing t bar". Another asks whether T-bar trains rear delts and traps. Exercise selection invites "you don't need X" debate.
- No rationale for equipment choices ("cable hammer curls rather than free weights?").
- Caption/slide naming mismatch (T-Bar Row (Chest Support) vs T-Bar Row; Preacher Curl vs DB Preacher Curl).
- Grammar slip on slide 3; exercise slides don't highlight target muscles (unlike the cover), so the anatomy art is decorative rather than instructive.
- CTA is weak/implicit — high saves but no explicit download prompt or app name on slides.
