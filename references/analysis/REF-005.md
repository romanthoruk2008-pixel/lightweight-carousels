## C. Marketing analysis

**Hook.** Imperative "how-to" promise + specific workout-split keyword: "STRUCTURE THE PERFECT PULL DAY". Works because (1) "pull day" is a high-intent identity term for PPL lifters, so it self-selects the audience instantly; (2) "perfect" + "structure" promises a finished, decision-free template; (3) the giant condensed type + bright-green keyword + clean anatomical render reads as premium/scientific and is legible at thumbnail size. No curiosity gap, no number in the hook — pure utility promise.

**Formula.** "Template slide + one slide per slot": title → checklist of 6 slots ("1x muscle (function)") → 6 numbered slides, each = one muscle/movement function + sets x reps + "Choose one of these exercises" + 2 exercise options → brand before/after. i.e. **"Build your perfect [split day]: 6 slots, pick 1 of 2 exercises per slot."** Caption reinforces the mechanic: "Choose one of each exercise and you have built the perfect pull day".

**Practical value / saveability.** High. A viewer gets a complete, ready-to-run pull workout (6 exercises, 12-18 working sets, set/rep ranges), with choice between a machine/cable and a free/alternative option per slot (works for different gyms). Function-based framing (adduction vs extension for lats) adds a "smart" educational layer. Saves 50.4K vs likes 68.5K confirms it's used as a gym reference.

**Retention mechanics.** Overview slide 2 creates an explicit checklist the viewer wants to "fill in" (open loop: which exercises?); green #1-#6 numbering shows progress; strictly consistent template (same layout, same 2-option split, same green divider) makes swiping effortless; each slide is skimmable in ~3 s; choose-your-own format invites mental participation. Final slide changes layout (two big figures), giving a visual payoff.

**CTA.** Implicit only, on the last slide: "Day 1 / Day 100 Of Using Arrow" before/after with ✗/✓ lists. No explicit "download", "link in bio", "follow", or "save this" on slides or in caption. The caption has no CTA beyond hashtags.

**Brand integration.** Soft sell: the brand appears only on the final slide (and the account handle). No app UI, no feature demonstration. Claimed benefits are generic: "Consistent Progress", "Personalised Plans", "Real Results" vs "No Progress / No Structure / No Results". The "No Structure" bullet ties back to the hook word "STRUCTURE" — the content slides demonstrate structure, then the app is positioned as the source of it. The visual identity (green accent, anatomical renders) is consistent across all slides, so the whole carousel functions as branding.

**Fitness claims to verify / questionable points.**
- "Day 1 vs Day 100 of using Arrow" shows a dramatic transformation (untrained → very muscular) — unrealistic in 100 days and an unsubstantiated results claim; for Lightweight this should NOT be copied as a literal results promise without compliance review.
- Lats via "shoulder adduction" (pulldown, pull-up) vs "shoulder extension" (close-grip seated row, pullover): broadly defensible biomechanics, but depends on grip/arm path (a neutral/close-grip pulldown is largely extension; a close-grip row also loads mid-back). Flag for verification if reused.
- T-Bar Row and Wide-Grip Machine Row as "Traps (Upper Back)": these mainly train mid/lower traps, rhomboids, rear delts and lats, not upper traps (shrug-type). The label "Traps (Upper Back)" is loose; verify wording.
- "Brachioradialis (forearm)" with hammer + reverse curls: correct primary-target selection, though both are also elbow-flexion (biceps/brachialis) work — the source of commenter confusion.
- Set/rep prescriptions (2-3 x 6-10 compounds; 2-3 x 8-12 isolation) are generic hypertrophy guidance, not cited; "perfect" is an absolute claim.
- Minor copy issues: "Pec Dec" (usually "Pec Deck"); list order on slide 2 does not match numbered slides; inconsistent colons; "Lat" vs "Lats", "Trapezius" vs "Traps".

**Weaknesses / pushback.** Most-liked comment ("ONE BICEP", 117 likes, 8 replies) says arm volume is too low; another commenter says two curl variations are redundant and notes "a lot of comments" on this. The biceps allocation is the polarising point (useful engagement bait, but worth anticipating). Also: no explanation of why adduction vs extension matters, no warm-up/progression guidance, and the app plug promises outcomes without showing any feature.
