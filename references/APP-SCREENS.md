# Екрани застосунку Lightweight

Це оригінальні продуктові матеріали для каруселей, фінальних слайдів і макетів із телефоном. Приклади чужих каруселей залишаються в CAROUSELS.md.

## Як додати екран
Відкрий цей файл на GitHub → Edit (олівець) → перетягни скриншот під потрібний APP-XXX → дочекайся завершення завантаження → Commit changes.

Мінімум: зрозуміла назва + один скриншот. Решту опису може заповнити координатор. Один розділ = один екран/стан. Інша мова, тема або інший стан отримує новий APP-ID, щоб агент не плутав варіанти.

Для макетів потрібен чистий скриншот екрана застосунку, без рамки пристрою, вікна Figma або робочого столу. Якщо є лише інший формат, додай його й познач — це не привід вигадувати чистий UI.

Файл зараз порожній; жодного реального екрана сюди ще не додано. Назви нижче — запропоновані місця, їх можна змінити.

## Правила використання агентами

- Джерело конкретного UI — реальний скриншот під APP-ID. Порожній розділ не є доказом наявності екрана або функції.
- Для завдання зафіксувати APP-ID, source commit, фактичний image URL, мову/тему й призначення. Читати лише потрібні екрани.
- Використовувати екран, який відповідає тексту та реальній функції в каруселі. Сам APP-ID не підтверджує релізний статус функції.
- Не вигадувати логотип, елементи UI, дані чи інші стани на заміну оригіналу. Не переписувати текст на екрані й не видавати генеративне наближення за точний скриншот.
- Скриншот сам по собі не затверджує стиль усіх каруселей. style_status залишається exploring.
- Обраний екран можна показати без рамки, у макеті телефону або в сцені з рукою — якщо цього потребує задум. Телефон не обов'язковий для кожного фіналу.
- Для збереження справжнього UI бажаний процес: окремо створити/згенерувати сцену з читабельною площиною дисплея, потім вставити оригінальний скриншот як шар із потрібною перспективою та маскою. Цей процес ще не реалізований.
- Якщо генератор перемальовує UI, називати це наближеним макетом. Якщо точне вставлення недоступне, повідомити конкретне обмеження; не стверджувати, що екран збережено точно.
- Генерація каруселей і перенесення екрану в макет мають виконуватися у погодженому хмарному середовищі; на комп'ютер власника нічого не завантажувати.
- Не запускати окремого рецензента, автоматичного післягенераційного QA або виправлень за власною ініціативою. Результат переглядає власник.
