# Пошук нової назви (2026-10-19)

Причина: USPTO LIGHTWEIGHT!, Reg. 8430632 (Lightweight LLC, клас 9 workout-tracking apps + 41), зареєстровано 2026-09-15; їхній застосунок №1 за "lightweight". "Light weight baby" / "Yeah buddy" — марки Ronnie Coleman. Перевірки: iTunes Search API (US/GB/DE), USPTO tmsearch JSON (live marks), RDAP домени. Не перевірено: EUIPO, Україна, соцмережі, носії мов. Не юридична консультація.

## Смак власника (з реакцій)
- Подобалось: Lightweight, Nothing Heavy (відкинуто: люди наберуть "heavy" → Hevy), Two More ("звучить прикольно").
- Не подобалось: Gigachad, Featherweight, Ego Lift, Bro Science, Built Different, Do You Even Lift, Gym Crush, Encore, Hardly ("як застосунок для слів"), Gym Goblin (у нас динозавр), Gymo/Liftr/Rexy, Few More / Muscle Memory / Gym Mode / Couple More (усі "no").
- Закономірність: прості фрази, які реально кажуть уголос у залі, зрозумілі всім, з іронією. Не сленгові іменники, не вигадані слова, не "розумні" слова.
- Виключено: light/lite, heavy/hevy, strong, схожість з конкурентами, реквізит (plate, bar, set, rep, iron…), інші істоти.
