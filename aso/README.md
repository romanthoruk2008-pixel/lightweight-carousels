# Lightweight — App Store Optimization (окрема гілка `aso`)

Ця гілка — робоча пам'ять ASO-проєкту. Вона **не мерджиться в `main`** і не стосується процесу каруселей (CLAUDE.md, AGENTS.md, docs/ тут не змінювалися й до ASO не застосовуються).

Мова спілкування з власником — українська. Публічні тексти App Store — англійська (US English першою).

## Стан на 2026-10-19

- Етап 1 (дослідження) завершено. Результати — у `research/`.
- Бренд: **Harda** (робоча назва, обрана власником; див. `research/naming.md`). В App Store Connect назва вже `Harda: Gym Workout Tracker`.
- Чернетка сторінки App Store: `drafts/app-store-v1.md` (назва/subtitle/keywords/promo/опис/план скриншотів).
- Наступне: перевірка ключових слів цифрами через Sonar API (trysonar.app; змінна середовища `SONAR_API_KEY`, заголовок `Authorization: Bearer <key>`, база `https://api.trysonar.app`, `GET /api/v1/keywords/metrics?qs=<до 25 слів через кому>&store=ios&country=us`; специфікація `https://trysonar.app/openapi.json`). AppTweak не вдалося активувати → фіналізація назви/subtitle/keywords → іспанська (Мексика) локалізація → скриншоти.

## Як продовжити в новій сесії
Прочитати цей файл, `drafts/app-store-v1.md` і `research/keywords-longlist.md` (топ-60 для перевірки). Інструкції про каруселі в CLAUDE.md до ASO-роботи не застосовуються; у `main` нічого не писати. Перші цифри — `research/keyword-metrics.md`. Правило відбору: релевантність; popularity ≥ 20; difficulty Sonar ≤ 35–40; 1–2 загальні запити (workout tracker) лишаються в назві.
Sonar (замість AppTweak): для US і пріоритетних ринків (GB, DE, ES/MX, FR, BR) отримати volume, difficulty, поточні ранги конкурентів (Hevy, Strong, Fitbod, Dropset…) для топ-60 і для токенів поля Keywords; не вигадувати цифри.

## Підтверджено власником для релізу

- iPhone + **Apple Watch** виходять разом. Годинник: запуск тренування, запис підходів, пульс. Робота годинника **без iPhone поруч** — «вроді би так», **треба перевірити перед тим, як писати це на сторінці**.
- **Apple Health** і **Strava** інтеграції.
- Запис тренування: підходи, повторення, вага, warm-up, supersets, drop sets; попередні результати поруч; таймер відпочинку.
- Власні routines / програми / редактор / папки / закріплення папок.
- Готові програми — базові (Full Body, PPL, 5x5 тощо), бібліотека поповнюватиметься.
- **Build a plan** працює повністю, враховує обмеження («хрустить плече» → прибирає відповідні вправи). На сторінці подавати як функцію застосунку, **не як роботу Серьожі**; без медичних обіцянок.
- **Bring existing**: імпорт програми зі скриншота, фото паперу, тексту, голосу → одразу готові routines.
- **CSV-імпорт з будь-якого застосунку, що експортує CSV**, з повною історією. Назви конкурентів у метаданих не використовувати.
- Каталог вправ з інструкціями та зображеннями м'язів, заміна вправи.
- Історія, календар, рекорди, базова статистика, вимірювання, фото прогресу.
- **Gym Bro**: друзі, sharing тренувань, спільний стрік, «kick» з push. На сторінці **не позначати як Premium** (базовий функціонал, імовірно, безкоштовний; другу Premium не потрібен). Правила стріку **не описувати** (зараз це лічильник надісланих тренувань обох друзів; правила зміняться). Вкладка зараз «Community», буде перейменована на Gym Bro.
- Вхід: Sign in with Apple, Google, email.
- kg/lbs і cm/in перемикаються (онбординг + налаштування). Для US-скриншотів — lbs.
- Мови інтерфейсу: English, Ukrainian, Russian, Polish, German, Dutch, French, Spanish, Portuguese (PT), Portuguese (BR), Italian, Turkish, Czech.
- Монетизація: ~$4.99/міс, ~$29.99/рік (US), trial 30 днів (все відкрито). AI-функції — Premium з безкоштовним місячним лімітом. На скриншотах про Premium/trial не писати; в описі — один нейтральний рядок + Terms of Use + Privacy Policy.
- Recovery mode — майбутнє, на сторінку першого релізу не йде.

## Серьожа (Seriozha)

- Маскот-динозавр, підколює користувача, roasts вимикаються.
- **Не називати його «gym bro»** у публічних текстах — це плутається з функцією Gym Bro. Описувати через характер (dino, який підколює).
- Не AI-тренер. На скриншотах — без лайки (правило Apple 2.3.8: усі візуали 4+).
- Написання імені потрібно уніфікувати (у макетах «Seryozha», в обговореннях «Seriozha»).
